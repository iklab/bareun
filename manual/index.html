⚡ 빠른 시작 — 업무 흐름

아래 순서대로 설정하면 빠르게 시작할 수 있습니다.

  1. 직원 관리에서 직원을 등록합니다 (이름, 직무, 시급, 계좌 등).
  2. 근무 관리에서 해당 직원의 요일별 근무 패턴을 등록합니다.
  3. 주별 근무표에서 근무 현황을 확인하고, 필요 시 특정 날짜의 근무를 개별 수정합니다.
  4. 월말에 근무요약에서 급여 집계를 확인하고 엑셀로 다운로드합니다.
  5. 일용직이 있다면 일용직 근무표에서 별도로 관리합니다.
01 · 시스템 개요

시스템 개요 & 로그인

BP 시프트 관리 프로그램의 전체 구성과 로그인 방법, 화면 레이아웃을 안내합니다.

🎯 프로그램 소개

BP 시프트 관리는 각 지점의 직원 근무 패턴을 등록하고, 주간·월간 근무표를 자동으로 생성하며, 급여 집계까지 처리하는 통합 근무 관리 솔루션입니다.

  • 요일별 근무 패턴 등록 후 자동으로 주간·월간 근무표 생성
  • 특정 날짜의 근무를 개별 수정 (결근 처리, 시간 변경 등)
  • 월말 근무 집계 및 급여 계산 엑셀 출력
  • 일용직 근무 별도 관리 및 현금지급 처리
  • 기준인원 파일 업로드 시 근무표에 자동 비교 반영

🔑 로그인

  1. 브라우저에서 관리자로부터 안내받은 프로그램 URL에 접속합니다.
  2. 관리자가 발급한 아이디와 비밀번호를 입력합니다.
  3. 로그인 버튼을 클릭하면 메인 화면으로 이동합니다.
로그인 계정이 없거나 비밀번호를 분실한 경우 본사 관리자에게 문의하세요.

02 · 직원 관리

직원 관리

직원 정보 등록·수정·삭제 및 직무, 시급, 계좌, 보건증 만료일 관리 방법을 안내합니다.

📋 화면 개요

📸 실제 화면 스크린샷

직원 관리 — 현재 지점의 직원 목록이 표시됩니다.

  • 상단 검색창에서 이름으로 실시간 검색 가능
  • 컬럼 헤더 클릭으로 이름·직무·급여·입사일·퇴사일 등 정렬 가능
  • 퇴사일이 입력된 직원은 퇴사일이 빨간색으로 표시됨

➕ 직원 추가

  1. 화면 우측 상단의 직원 추가 버튼을 클릭합니다.
  2. 팝업에서 아래 정보를 입력합니다.
  3. 저장 버튼을 클릭하면 직원이 등록됩니다.
📸 실제 화면 스크린샷

직원 추가 팝업 — 필수 항목(직무, 이름, 입사일)을 입력하고 저장합니다.

입력 항목

항목필수설명
직무필수 직무 목록에서 선택 (예: 홀/정직원, 주방/파트타임 등). 직무가 없다면 관리자에게 요청
이름필수직원 실명 입력
시급선택숫자만 입력 (예: 10030). 근무요약 급여 계산에 사용됨
주민등록번호선택 000000-0000000 형식. 숫자만 입력하면 하이픈 자동 추가됨
은행 / 계좌번호선택급여 이체용 계좌 정보
이메일 / 휴대폰선택연락처 정보
건강검진 만료일선택보건증 만료 날짜. 만료 관리에 활용
입사일필수달력에서 날짜 선택
퇴사일선택 퇴사한 경우에만 입력. 퇴사일 이후 근무 등록이 차단됨
직무 선택 시 색상 동그라미가 함께 표시됩니다. 이 색상은 주별 근무표에서 해당 직원의 근무 바 색상으로 사용됩니다.

✏️ 직원 수정 / 삭제

  • 수정할 직원 행의 우측 수정 버튼 → 내용 변경 후 저장
  • 삭제할 직원 행의 우측 삭제 버튼 → 확인 팝업에서 확인
퇴사 직원은 삭제 대신 퇴사일을 입력하는 방식을 권장합니다. 퇴사일 입력 시 해당 날짜 이후 근무 등록이 자동으로 차단됩니다.
직원을 삭제하면 해당 직원의 근무 데이터도 함께 삭제될 수 있습니다. 퇴사 처리는 퇴사일 입력을 사용하세요.

03 · 근무 관리

근무 관리

직원별 요일별 근무 패턴을 등록하고, 근무1/2·휴게·필드·적용 기간을 설정하는 방법을 안내합니다.

💡 근무 관리란?

근무 관리는 직원의 반복적인 주간 근무 패턴을 등록하는 곳입니다. 예를 들어 "홍길동은 월~금 09:00~18:00, 토·일 휴무"처럼 패턴을 한 번 등록하면, 해당 기간 동안 주별 근무표에 자동으로 표시됩니다.

패턴 vs 개별 수정: 근무 관리에서는 반복 패턴을 등록합니다. 특정 날짜만 임시로 변경하려면 주별 근무표에서 개별 수정하세요.

📋 목록 화면

📸 실제 화면 스크린샷

근무 관리 — 등록된 근무 패턴 목록. 직원 이름으로 검색하거나 컬럼 헤더로 정렬할 수 있습니다.

  • 이름·직무명·적용 시작일·적용 종료일 기준 컬럼 헤더 클릭 정렬 가능
  • 상단 검색창에서 직원 이름으로 검색 가능
  • 한 직원이 여러 개의 근무 패턴을 가질 수 있음 (기간별로 다른 스케줄)

➕ 근무 추가

  1. 우측 상단 근무 추가 버튼 클릭
  2. 직원 선택 드롭다운에서 직원 이름을 검색하여 선택
  3. 요일별 근무 시간 입력 (아래 상세 설명 참고)
  4. 적용 기간 설정 후 저장 클릭
📸 실제 화면 스크린샷

근무 추가 팝업 — 요일별로 근무1/근무2·휴게·필드·비고를 설정하고 적용 기간을 지정합니다.

📅 요일별 근무 시간 설정

월~일 7개 요일에 대해 각각 설정합니다.

휴무 설정

해당 요일의 휴무 체크박스를 체크하면 근무 없이 휴무 처리됩니다. 체크 시 시간 입력 영역이 숨겨집니다.

근무1 (메인 근무)

항목설명예시
시작 ~ 종료근무 시작·종료 시간09:00 ~ 18:00
휴게↑ ~ 휴게↓휴게 시작·종료 시간13:00 ~ 14:00
필드근무 배치 영역 선택홀 / 주방

근무2 (스플릿 근무)

한 직원이 하루에 두 번 출근하는 경우 (오전 근무 후 휴식, 오후 재출근) 근무2에 별도 시간을 입력합니다.

항목설명
시작 ~ 종료두 번째 근무 시간
휴게↑ ~ 휴게↓두 번째 근무 중 휴게 (선택)
필드2두 번째 근무의 배치 영역. 근무1과 다를 경우 주별 근무표에서 별도 행으로 표시
근무2의 필드가 근무1과 다르면 주별 근무표에서 해당 직원이 두 개의 필드 행에 각각 표시됩니다.

요일별 비고

해당 요일의 포지션, 특이사항 등 메모. 주별 근무표의 비고 칸에 표시됩니다.

시간 입력 필드에 4자리 숫자로 입력하면 자동으로 시:분 형식으로 변환됩니다 (예: 0900 → 09:00).

📆 적용 기간 설정

항목설명
적용 시작일 필수 이 패턴을 적용하기 시작할 날짜. 이 날짜 이후 주별 근무표에 반영됨
적용 종료일 선택 패턴 종료일. 입력하지 않으면 계속 유지됨. 계약 만료일이 있는 경우 입력
퇴사 직원의 경우, 적용 시작일이 퇴사일 이후이거나 적용 종료일이 퇴사일을 초과하면 저장 오류가 발생합니다.

🔄 근무 패턴 변경 시 처리 방법

직원의 스케줄이 바뀌는 경우 다음과 같이 처리합니다.

  1. 기존 패턴의 수정을 클릭하고 적용 종료일을 변경 전날로 설정합니다.
  2. 근무 추가로 새로운 패턴을 등록하고 적용 시작일을 변경 당일로 설정합니다.
이렇게 하면 날짜별로 올바른 패턴이 주별 근무표에 자동으로 표시됩니다.

04 · 주별 근무표

주별 근무표

주차별 시간대 근무 현황 조회, 결근 처리, 비고 수정, 근무 개별 수정 및 엑셀 다운로드 방법을 안내합니다.

📋 화면 개요

📸 실제 화면 스크린샷

주별 근무표 — 06:00~22:30 시간대를 30분 단위 바(bar)로 근무 현황을 시각화합니다.

  • 06:00 ~ 22:30 시간대를 30분 단위 칸으로 표시
  • 근무 중인 시간대는 색칠된 막대로 표시 (필드별 색상)

🚫 결근 처리 & 원복

결근 처리

  1. 해당 직원의 날짜 칸 클릭 → 근무 수정 팝업 열기
  2. 결근 체크박스 체크
  3. 저장 클릭

결근 처리 후 해당 행 배경이 연한 빨간색으로 바뀌고 결근 배지가 표시됩니다.

결근 원복 관리자 전용

잘못 처리된 결근을 취소하고 원래 패턴으로 복원합니다.

  1. 결근 처리된 직원의 날짜 칸 클릭
  2. 팝업 하단의 결근 원복 버튼(주황색) 클릭
  3. 확인 시 해당 날 수정 내용이 삭제되고 원래 패턴으로 복원
결근 원복 버튼은 결근 상태인 경우에만 팝업 하단에 표시되며, 관리자 계정에서만 클릭 가능합니다.

📝 비고 수정

직원 행의 비고 칸을 클릭하면 별도 팝업에서 빠르게 수정할 수 있습니다.

  1. 비고를 수정할 직원의 비고 칸(이름 오른쪽) 클릭
  2. 비고 수정 팝업에서 내용 입력
  3. 저장 클릭
비고에 포지션명(카운터, 홀1, 주방장 등)을 입력하면 엑셀 출력 시에도 함께 표시됩니다.

05 · 근무요약

근무요약

월별 직원별 근무일수·근무시간·급여를 집계하고 엑셀로 내보내는 방법을 안내합니다.

📊 화면 개요

📸 실제 화면 스크린샷

근무요약 — 현재 달 직원별 근무일수·시간·급여가 자동 집계됩니다.

  • 직원별 해당 월 총 근무일수, 근무시간, 시급, 총급여 자동 계산
  • 이름·직무·입사일·근무일수·시간·급여 기준 컬럼 클릭 정렬
  • 상단 검색창에서 이름·직무로 실시간 검색

🗓️ 월 이동

상단 좌측의 ◀ / ▶ 버튼으로 이전/다음 달로 이동합니다. 이동 즉시 해당 월 집계가 다시 조회됩니다.

📋 목록 컬럼 설명

컬럼설명
이름직원 이름
직무직원의 직무 (필드/고용형태)
입사일 / 퇴사일없으면 '-'
주민등록번호급여 신고 등에 활용. 없으면 '-'
계좌번호은행·계좌 정보. 없으면 '-'
근무일수해당 월 실제 근무한 날 수 (결근·휴무일 제외)
근무시간해당 월 총 근무 시간 (0.5시간 단위, 휴게 제외)
시급/급여직원 관리에 입력된 시급 (원 단위)
총급여근무시간 × 시급 계산값. 파란색 굵게 표시
총급여는 근무시간 × 시급으로 자동 계산됩니다. 시급이 없는 직원은 '-'로 표시됩니다.

⬇️ 근무요약 엑셀 다운로드

  1. 우측 상단 근무요약 버튼(다운로드 아이콘)을 클릭합니다.
  2. 현재 월 전체 직원 집계가 포함된 엑셀 파일이 자동 다운로드됩니다.

파일명: 근무요약_YYYYMM.xlsx

검색·필터 상태와 무관하게 전체 직원 데이터가 엑셀에 포함됩니다.

📦 통합 다운로드

근무요약과 월간근무표를 하나의 엑셀 파일(시트 2개)로 한 번에 다운로드합니다.

  1. (선택) 기준인원 파일이 있다면 기준인원 업로드 버튼으로 먼저 업로드합니다.
  2. 우측 상단 통합 다운로드 버튼(파란색)을 클릭합니다.
  3. 근무요약 + 월간근무표가 하나의 파일로 다운로드됩니다.

파일명: 통합_YYYYMM.xlsx

👥 기준인원 파일 업로드

  1. 기준인원 업로드 버튼을 클릭하고 양식에 맞게 작성된 파일을 선택합니다.
  2. 버튼이 초록색으로 바뀌고 파일명이 표시되면 로드 성공입니다.
  3. 통합 다운로드를 클릭하면 기준인원 포함 파일이 생성됩니다.
  • 초기화를 클릭하면 업로드된 파일이 제거됩니다.
  • 기준인원 양식 파일은 주별 근무표 다운로드 팝업의 기준인원 양식 다운로드에서 받을 수 있습니다.
기준인원 파일 형식과 작성 방법은 엑셀 다운로드 가이드를 참고하세요.

06 · 일용직 근무표

일용직 근무표

일용직 직원 등록, 월별 달력형 근무 입력, 급여·현금지급 처리 및 엑셀 다운로드 방법을 안내합니다.

💡 일용직 관리란?

고정 패턴 없이 날짜별로 근무가 달라지는 일용직(아르바이트, 단기 인력 등)을 관리하는 화면입니다. 직원 관리의 정직원과 별도로 관리되며, 월별 달력 형태로 날짜를 클릭해 근무를 직접 입력합니다.

일용직은 패턴 등록 없이 날짜별로 직접 입력합니다. 주별 근무표에도 일용직 항목이 함께 표시됩니다.

📋 화면 구성

📸 실제 화면 스크린샷

일용직 근무표 — 직원별로 날짜 칸을 클릭해 근무를 입력합니다. 색상으로 필드와 지급 상태를 확인할 수 있습니다.

  • 왼쪽 고정: 지점, 성명, 주민등록번호, 체류자격, 은행명, 계좌번호, 예금주명
  • 가운데: 해당 월 날짜별 컬럼 (1일~말일). 날짜 헤더에 요일도 함께 표시
  • 근무 입력된 날: 필드에 따라 파란색(홀) / 주황색(주방) 표시
  • 입금·현금지급 완료 날: 회색 표시

👥 기준인원 파일 작성 방법

기준인원 파일은 시간대별로 배치해야 할 목표 인원 수를 입력하는 엑셀 파일입니다. 업로드하면 실제 근무인원과 나란히 비교됩니다.

양식 파일 받기

  1. 주별 근무표에서 주간근무표 또는 월간근무표 버튼 클릭
  2. 팝업 하단의 기준인원 양식 다운로드 링크 클릭
  3. 빈 양식 파일 기준인원양식.xlsx 다운로드됨

양식 작성 규칙

  • 양식 파일의 형식을 변경하지 마세요 (행·열 위치 고정)
  • 각 시간 슬롯에 해당 필드의 기준 인원 수(숫자)를 입력
  • 비워두면 해당 슬롯은 기준인원 없음으로 처리됨

업로드 방법

  1. 주별 근무표 다운로드 팝업 또는 근무요약 화면의 기준인원 파일 선택 / 업로드 버튼 클릭
  2. 작성된 파일 선택
  3. 버튼이 초록색으로 바뀌면 로드 완료
  4. 다운로드 버튼 클릭 시 기준인원 포함 파일 생성
기준인원 파일은 제공된 양식만 사용해야 합니다. 임의로 형식을 변경하면 파싱 오류가 발생합니다.

❓ 자주 묻는 질문

Q. 엑셀 파일이 열리지 않아요.

다운로드된 파일의 확장자가 .xlsx인지 확인하세요. Microsoft Excel 또는 Google Sheets로 열 수 있습니다.

Q. 기준인원 파일 업로드 후 "파싱 실패" 오류가 나요.

반드시 시스템에서 다운로드한 기준인원 양식 파일을 사용해야 합니다. 직접 만든 파일이나 형식이 다른 파일은 업로드되지 않습니다.

Q. 근무요약 엑셀에 일부 직원이 없어요.

해당 월에 근무 패턴이 없거나, 퇴사일이 해당 월 이전인 직원은 집계에서 제외될 수 있습니다. 직원 관리에서 근무 패턴과 퇴사일을 확인하세요.

Q. 통합 다운로드와 근무요약 다운로드의 차이는?

통합 다운로드는 근무요약(1시트) + 월간근무표(1시트)를 하나의 파일에 담은 것입니다. 월말 보고서를 한 파일로 처리할 때 편리합니다.
